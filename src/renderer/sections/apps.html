How apps use config vars

Config vars are per-app secrets: the key is visible below, the value is encrypted on this machine before it's stored and can never be viewed again — not here, not by the server. Delete and re-add a var to rotate it.

A Glyphh app that declares the secrets.get capability reads its own vars at runtime — e.g. an agentic app fetching the key it needs: 

await glyphh.call("secrets.get", { key: "OPENAI_API_KEY" })
// → { value: "sk-…" }   (only app code sees it, never the UI)

agent.run and llm.complete pick keys up automatically: a var named ANTHROPIC_API_KEY / OPENAI_API_KEY / GOOGLE_API_KEY powers that provider with no code at all. Keys belong to the app — Glyphh has no key store and makes no model calls of its own.
