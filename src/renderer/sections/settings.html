MCP Server

Connect Claude, Cursor, or any MCP-capable client to your organization's tools — build, connect, and drive rotors, agents and loops — over the cloud endpoint, authorized with OAuth or an API key.

OAuth — in Claude, add the endpoint as a connector; approve the connection on the Glyphh consent screen and it's live. Any OAuth-capable client works the same way.

API keys — for clients that can't OAuth, create a key under Organization → API Keys and send it as a Bearer token.

Connected clients

Clients you've authorized over OAuth. Revoking one cuts its access immediately without signing you out anywhere.
